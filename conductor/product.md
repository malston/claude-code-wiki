# Product Definition

## Project

| Field       | Value                                                                  |
| ----------- | ---------------------------------------------------------------------- |
| Name        | claude-code-wiki                                                       |
| Description | A knowledge base wiki about Claude Code internals, patterns, and usage |
| Repository  | github.com/malston/claude-code-wiki                                    |
| URL         | https://malston.github.io/claude-code-wiki/                            |

## Problem Statement

Teams adopting Claude Code lack practical guidance beyond the official getting-started docs. The official documentation covers setup and basic usage but stops short of the depth needed for daily workflows, advanced configuration, and organizational rollout.

## Target Users

1. **Developers using Claude Code for daily work** -- need guides on prompting, debugging, testing, context management, and extending the tool
2. **Platform engineers rolling out Claude Code to their organizations** -- need enterprise rollout playbooks covering infrastructure, permissions, managed settings, cost tracking, and phased adoption

## Key Goals

1. **Practical depth** -- go deeper than official docs with verified patterns, real configurations, and concrete examples
2. **Enterprise readiness** -- provide a complete rollout playbook from infrastructure to observability
3. **Stay current** -- keep content updated as Claude Code evolves across releases
