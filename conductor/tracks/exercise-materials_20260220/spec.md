# Specification: Training Exercise Materials

**Track ID:** exercise-materials_20260220
**Type:** Feature
**Created:** 2026-02-20
**Status:** Draft

## Summary

Create standalone exercise repos for each training path persona, providing pre-built starter materials so participants can practice module concepts without creating their own context.

## Context

The claude-code-wiki training section has three role-based learning paths (developer, platform engineer, product manager), each with exercises that currently ask users to supply their own codebase and scenarios. Providing ready-made repos removes this friction and ensures consistent learning experiences.

## User Story

As a training path participant, I want pre-built exercise materials (starter files, sample codebases, scenario descriptions) so that I can practice each module's concepts without having to create my own context from scratch.

## Acceptance Criteria

- [ ] Each exercise in the three training paths has accompanying starter materials
- [ ] Materials are self-contained -- a user can start an exercise without needing an existing codebase
- [ ] Three separate repos under `~/code/` (one per persona) with persona-specific CLAUDE.md and settings
- [ ] Training articles link to the corresponding exercise repos
- [ ] Hugo builds cleanly

## Dependencies

Depends on completed training path articles from `training-section_20260220` track (exercises reference specific modules).

## Out of Scope

- Video or multimedia content
- Automated grading or assessment
- Solutions/answer keys (exercises are open-ended, verified by running tests or Claude Code)
- Modifications to the training path articles themselves (beyond adding links to exercise repos)

## Technical Notes

- **Developer repo:** Java/Spring backend + TypeScript/Next.js frontend
- **Platform engineer repo:** Terraform configurations and infrastructure setup
- **Product manager repo:** Mock product backlog + development codebase (for submitting PRs)
- PMs need access to actual code so they can practice reviewing and contributing PRs
- Each repo gets its own CLAUDE.md and project-specific settings
